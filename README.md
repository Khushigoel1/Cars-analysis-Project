# Cars-analysis-Project

A **Data Analysis and Machine Learning project** that analyzes used-car data and predicts car selling prices using **Linear Regression**.

## 📌 Features

* Exploratory Data Analysis (EDA)
* Data visualization using Matplotlib & Seaborn
* Correlation analysis
* Data preprocessing and feature scaling
* Car price prediction using Linear Regression
* Model evaluation using **MAE, MSE & R² Score**

## 🛠️ Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 📊 Dataset

The dataset contains information such as **car name, year, present price, selling price, kilometers driven, fuel type, seller type, transmission, and owner**.
